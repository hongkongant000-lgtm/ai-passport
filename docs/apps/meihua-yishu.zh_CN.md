# 梅花易数 — 即时问、即时数

AI Passport 衍生应用：选定所问后，按当下民用时间起卦，显示本卦 / 互卦 / 变卦 /
体用与简要断语。

## 界面（里程碑 1）

| 页面 | 按键 |
| --- | --- |
| 提问 | 上/下切换题库；确定立即起卦 |
| 结果 | 三列卦画、体用、短断语；确定返回；长按确定再次起卦 |

电量计可用时在右上角显示 SOC。界面为全新墨色纸感 LVGL 壳，不使用基线
demo 菜单或 `ui_pixel`。

## 时间起卦算法

固件采用有文档约定的古典 **时间起卦**（邵雍梅花易数风格），作用在设备民用时钟：

1. **年数** — 公元年对应的地支序数：`((year - 4) % 12) + 1`（子=1 … 亥=12）。
   例：1984 → 1，2026 → 7（午）。
2. **月 / 日** — 民用月（1–12）与日（1–31）。
3. **时数** — 本地小时对应的时辰 1–12（子时跨 23:00–00:59）。
4. **上卦** — `(年+月+日) % 8`，余 0 记为 8（坤）。
5. **下卦** — `(年+月+日+时) % 8`，余 0 记为 8。
6. **动爻** — `(年+月+日+时) % 6`，余 0 记为 6（初爻=1）。

卦序为梅花易数所用先天八卦数：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8。

**互卦**：二三四爻为下、三四五爻为上。
**变卦**：翻转本卦动爻。
**体用**：动爻在下卦（1–3）则下为用、上为体；在上卦（4–6）则上为用、下为体。

里程碑 1 的断语为体用五行生克短句（比和 / 体生用 / 用生体 / 体克用 / 用克体）。
更丰富断语与 Flash 存档留待后续里程碑。

若 RTC 未设置（`year < 2020`），回退到文档约定时间 `2026-11-15 10:00`，
保证离线起卦可复现；需要即时时间请先校时。

## 中文字体

里程碑 1 使用 `assets/fonts/meihua_font_16.c`：Adobe Source Han Sans SC（OFL）
的 16 px / 4 bpp LVGL 子集，覆盖提问/结果页文案、卦名、ASCII 数字与中文标点。
文案变更后需用 `lv_font_conv` 重新生成。各页实际显示仍须实机确认。
